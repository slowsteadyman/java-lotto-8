# java-lotto-precourse

---

## 🎰 초간단 로또 발매기 설명서

- 사고 싶은 만큼 로또를 구매합니다. (1장 당 1,000원)
- 당첨 번호와 보너스 번호를 추첨합니다.
- 당첨 결과와 내 수익률을 확인합니다.

### 사용 예시
```
구입금액을 입력해 주세요.
8000

8개를 구매했습니다.
[8, 21, 23, 41, 42, 43] 
[3, 5, 11, 16, 32, 38] 
[7, 11, 16, 35, 36, 44] 
[1, 8, 11, 31, 41, 42] 
[13, 14, 16, 38, 42, 45] 
[7, 11, 30, 40, 42, 43] 
[2, 13, 22, 32, 38, 45] 
[1, 3, 5, 14, 22, 45]

당첨 번호를 입력해 주세요.
1,2,3,4,5,6

보너스 번호를 입력해 주세요.
7

당첨 통계
---
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
총 수익률은 62.5%입니다.
```
---

## ✅ 구현할 기능

- 입력 받기 (Input.java)
  - 구입금액
  - 당첨번호 / 보너스번호
- 입력값 검증
  - 구입금액: 숫자, 1000의 배수
  - 당첨번호: 숫자, 45 아래, 중복 x, 6개 추첨
  - 보너스번호: 숫자, 45 아래, 중복 x
  - **잘못된 입력일 경우, 에러 메시지 출력 후 다시 입력 받기**
- 로또 진행
  - 로또 구매
    - 구매한 개수만큼, 중복 x
  - 로또별 당첨 여부 확인
- 출력
  - 당첨 내역
  - 수익률
